# smart.delivery.planning-fractional.knapsack
Menu-driven C implementation of the Fractional Knapsack Greedy Algorithm for smart delivery planning, maximizing package value under a vehicle's weight capacity.
## 📌 Project Overview

This project implements the Fractional Knapsack Greedy Algorithm to maximize the value of packages carried by a delivery vehicle with limited capacity.

## 🎯 Objectives
- Understand the Greedy Method.
- Calculate the value-to-weight ratio of packages.
- Sort packages using Bubble Sort.
- Maximize the total value within the given capacity.

## 🛠️ Technologies Used
- Language:C
- Algorithm: Fractional Knapsack (Greedy Method)
- Concepts: Arrays, Functions, Bubble Sort

## ✨ Features
- Menu-driven program.
- Accepts package values, weights, and vehicle capacity.
- Sorts packages by value-to-weight ratio.
- Displays selected packages and maximum achievable value.

## 📊 Sample Input

| Package | Value | Weight |
|---|---:|---:|
| P1 | 40 | 5 |
| P2 | 30 | 10 |
| P3 | 50 | 5 |
| P4 | 20 | 4 |

Vehicle capacity: 15

## ✅ Expected Result
- P3, P1, and P4 are selected completely.
- Total weight used: 14
- Maximum value: 110

## ▶️ How to Run
1. Save the code as `fractional_knapsack.c`.
2. Compile using:
   `gcc fractional_knapsack.c -o knapsack`
3. Run the compiled program.

## ⏱️ Complexity Analysis
- **Time Complexity:** O(n²), due to Bubble Sort.
- **Space Complexity:** O(n), for storing package details.
